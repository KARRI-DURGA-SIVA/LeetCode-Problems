# LeetCode 1301 - Number of Paths with Maximum Score

## Problem
Find the maximum score that can be collected while moving from **S** to **E**, and return the number of paths that achieve this maximum score. If no path exists, return `[0, 0]`.

## Difficulty
**Hard**

## Test Cases

### Example 1
**Input:**
```
["E23","2X2","12S"]
```

**Output:**
```
[7,1]
```

### Example 2
**Input:**
```
["E12","1X1","21S"]
```

**Output:**
```
[4,2]
```

### Example 3
**Input:**
```
["E11","XXX","11S"]
```

**Output:**
```
[0,0]
```

## Complexity

- **Time Complexity:** `O(n²)`
- **Space Complexity:** `O(n²)`
